## Feedback System

When the user taps "👍 Useful" or "👎 Not useful":

1. Feedback is saved in state
2. Card shows "✅ Thanks!" or "📝 We'll improve"
3. System learns from feedback:
   - If user marks "Cost" insights as "Not useful" 2+ times
   - Future days will show fewer cost-related insights
   - Other categories will be prioritized
